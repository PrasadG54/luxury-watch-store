# Luxury Watch Store

A modern luxury watch website built as a Cloud Computing academic project. The website is inspired by premium watch brands such as Patek Philippe and focuses on elegant design, smooth user experience, and responsive layouts rather than online selling.

---

## Project Overview

This project is developed as a college Cloud Computing project.

Instead of an e-commerce platform, the website showcases luxury watches, brand heritage, collections, and allows users to book appointments.

The main objective is to demonstrate modern web development techniques and deploy the project using cloud technologies.

---

- Luxury Landing Page
